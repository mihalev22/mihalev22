## 📋 [RequireX — из записи встречи в готовое ТЗ](https://github.com/mihalev22/Hacktion)

Командный проект хакатона **X<актион> ТехЗадание**

Загружаешь аудио- или видеозапись встречи с заказчиком — сервис расшифровывает её с разделением по спикерам и собирает **проверяемое техническое задание**: требования с дословными цитатами, таймкодами, приоритетами, открытыми вопросами и найденными противоречиями.

- `FastAPI` · `React 19 + TypeScript` · `GigaChat` · `Docker Compose` · `SQLite`
- Ответы LLM не берутся на веру: каждая цитата перепроверяется на бэкенде через `rapidfuzz` — получается честный confidence
- JWT-аутентификация с refresh-токенами, роли доступа к проектам, admin-панель
- Клик по требованию прокручивает транскрипт к источнику с таймкодом
- Поднимается одной командой `docker compose up --build`

## 🖼 [ML-улучшение фото — прямо в браузере](https://mihalev22.github.io/ml-image-enhancement/)

[**Живое демо**](https://mihalev22.github.io/ml-image-enhancement/) — без регистрации, всё считается локально на устройстве, фотографии никуда не загружаются.

- `TensorFlow.js` — модель в браузере подбирает яркость, контраст и насыщенность
- `HEIC → JPEG` на лету для фото с iPhone, сравнение «до / после», ручная доводка
- Обработка разбита на чанки — интерфейс не подвисает даже на больших фото
